# 支持的本地导入格式

| 格式 | 规则 |
| --- | --- |
| Markdown (`.md`, `.markdown`) | 首个 `# 标题` 作为标题，其余内容作为正文；无标题时使用文件名。 |
| TXT (`.txt`) | 文件名作为标题，全文作为正文。 |
| JSON (`.json`) | 对象或对象数组；每项必须包含非空 `title` 和 `body`。 |
| CSV (`.csv`) | 必须包含 `title` 与 `body` 列；每行生成一个候选项。 |

导入不发布内容。空标题、空正文、损坏 JSON/CSV 或不支持扩展名会被拒绝。文件夹扫描会递归处理受支持格式，并跳过符号链接。

完全相同的规范化正文会被视为重复并跳过；相似但不相同的候选项仍由用户在收件箱中审核。
