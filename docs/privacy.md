# 本地隐私与数据边界

Prompt Hub 的核心提示词库使用本机 SQLite 数据库。备份也保存在本机数据目录。文件和文件夹导入仅在本地解析；网页 URL 导入会向用户提供的公开地址发起受限请求，以提取文本。MCP 通过显式配置的本地数据库路径访问数据。

首发版本不提供数据库加密或应用锁。能访问当前 Windows 用户数据目录或已复制数据库/备份文件的人，可能读取其中的提示词内容；请使用受系统保护的用户帐户、设备加密和受控备份位置。不要将数据库或备份放入公开共享目录。

诊断界面不显示提示词正文、密钥或授权头。核心工作流不要求 AI 提供商凭据。配置 OpenAI 兼容 AI 接口时，API 密钥只使用操作系统凭据存储，不能写入数据库、日志、测试夹具或仓库文件；请求仅发送到用户配置的 HTTPS 接口。

外部来源、AI 与 MCP 的写入必须先进入收件箱，不能覆盖已发布提示词。

永久清除仅能由桌面端对已软删除提示词发起，且会先创建本地安全备份；AI 与 MCP 没有永久清除入口。
