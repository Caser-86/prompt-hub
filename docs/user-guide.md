# Prompt Hub 用户指南

Prompt Hub 是本地优先的提示词资产库。创建、编辑、搜索、收藏、版本历史、备份和本地文件导入均不依赖 AI 提供商凭据。

## 管理提示词

在“提示词库”创建提示词。草稿先进入收件箱；补齐分类或标签后可发布。发布后的编辑和历史恢复会生成新版本。归档、软删除和恢复均保留操作记录；批量归档需要确认且可恢复。

可为提示词记录来源、适用工具与模型、验证状态和评分，并可将常用提示词设为收藏。

## 搜索

搜索支持中文文本、有效性、评分、生命周期、来源、分类、标签、工具、模型、更新时间和收藏筛选。结果分页稳定；“保存当前视图”将当前检索条件保存在本机浏览器存储中。

## 导入

在“收件箱”输入本地文件路径后导入。导入结果始终是待审核草稿，不会自动发布。完全相同的规范化正文会被跳过并显示数量。

## 备份与恢复

在“设置 → 备份与恢复”创建本机备份。恢复前先检查备份完整性和内容预览；确认恢复时会自动创建恢复前安全备份。
