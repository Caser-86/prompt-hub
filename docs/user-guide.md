# Prompt Hub 用户指南

Prompt Hub 是本地优先的提示词资产库。创建、编辑、搜索、收藏、版本历史、备份以及本地文件、文件夹和网页导入均不依赖 AI 提供商凭据。

## 管理提示词

在“提示词库”创建提示词。草稿先进入收件箱；补齐分类或标签后可发布。发布后的编辑和历史恢复会生成新版本。归档、软删除和恢复均保留操作记录；批量归档需要确认且可恢复。

可为提示词记录来源、适用工具与模型、验证状态和评分，并可将常用提示词设为收藏。词库默认优先展示收藏项，其次按本机打开或复制次数排序；收藏使用五角星切换，已收藏为醒目的金色实心星。

需要整理多条提示词时，勾选每条右侧的复选框会显示“批量管理”提示条。提示条会明确显示已选数量，并提供“归档已选”和“取消选择”；归档不会删除内容，之后可在详情中恢复。

## 搜索

顶部 Ctrl+K 命令面板用于快速定位：可按标题、标签和来源打开提示词，也可执行常用导航操作。左侧导航不再单独放置“搜索”，避免与顶部入口重复。

需要组合条件时，在“提示词库”页面选择“高级筛选”。高级筛选支持中文文本、有效性、评分、生命周期、来源、分类、标签、工具、模型、更新时间和收藏筛选；“保存当前视图”将当前检索条件保存在本机浏览器存储中。

## 导入

在“收件箱”输入本地文件或文件夹路径，或粘贴公开网页 URL 后导入。文件夹会递归扫描支持的格式，网页仅接受 HTTP/HTTPS 的文本响应；本机、私有网络、含凭据的地址会被拒绝。导入结果始终是待审核草稿，不会自动发布。

完全相同的规范化正文会被跳过并显示数量。每次导入都会产生本地任务记录，记录成功、重复或失败的数量；失败项可在收件箱再次发起导入。

## AI 草稿

在“设置 → AI 草稿”中可使用 HTTPS 的 OpenAI 兼容接口生成提示词草稿。API 密钥通过系统凭据存储保存；生成结果会标记模型、生成时间和输入摘要，并只进入收件箱。未配置凭据时，离线核心功能仍可正常使用。

## Codex MCP

在“设置 → Codex MCP”查看当前数据库路径和可复制配置。将配置加入 Codex 后，`prompt-mcp` 可搜索、读取和渲染本地提示词；它创建的内容只能作为收件箱草稿，不能直接改写已发布提示词。

## 备份与恢复

在“设置 → 备份与恢复”创建本机备份。可选填备份目录；留空时使用默认本机备份目录。恢复前先检查备份完整性和内容预览；确认恢复时会自动创建恢复前安全备份。可输入保留份数清理旧备份；清理范围会显示在操作结果中。

软删除的提示词可在详情页恢复。若确需永久清除，只能对已软删除项操作：输入完整标题二次确认后，系统会先创建并验证本地安全备份，再移除该提示词及其版本历史；操作完成后会显示备份路径。
